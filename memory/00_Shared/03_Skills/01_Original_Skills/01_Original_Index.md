# 01_Original_Skills_Index.md - OpenClaw System Skills

ဤဖိုင်သည် OpenClaw စနစ်တွင် ပါဝင်သော ပင်မအရည်အချင်းများ (Original Skills) ၏ အနှစ်ချုပ် ဖြစ်သည်။

## 🛠️ Productivity & Tools
- **github:** GitHub repository များ စီမံခြင်း (Issues, PRs)။
- **weather:** ကမ္ဘာတစ်ဝှမ်း မိုးလေဝသ အခြေအနေ စစ်ဆေးခြင်း။
- **notion:** Notion workspace တွင် စာမျက်နှာများ ရေးသားခြင်း။
- **gog:** Google Workspace (Gmail, Drive, Docs) နှင့် ချိတ်ဆက်ခြင်း။

## 🔍 Search & Data
- **ripgrep-search:** ဖိုင်များအတွင်း စာသားများကို လျှပ်စစ်လို မြန်မြန် ရှာဖွေခြင်း။
- **browser:** Web browser ကို အသုံးပြု၍ သတင်းအချက်အလက် ရှာဖွေခြင်း။

## 🛡️ System & Maintenance
- **healthcheck:** VPS လုံခြုံရေးနှင့် ကျန်းမာရေး စစ်ဆေးခြင်း။
- **tmux:** Interactive command-line sessions များကို စီမံခြင်း။
