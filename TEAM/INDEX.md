## ⚙️ Routing Logic (The Nolan Protocol)

1.  **Incoming Request:** Nolan talks to David.
2.  **Analysis:** David identifies the domain (Strategy, Research, Dev, Operations, or Copy).
3.  **Activation:** David spawns the corresponding specialist using `sessions_spawn`.
4.  **Execution:** The Specialist performs the task and returns the result to David.
5.  **Delivery:** David reviews and presents the final value to Nolan.
    *   *Example:* If Nolan asks for a VPN ad, David spawns **Ghost**. If Nolan asks to deploy a new server, David spawns **Ko Thiha**.
