# ကိုယ်ပိုင်အုပ်ချုပ်ခွင့်ရ AI အေးဂျင့် အဖွဲ့အစည်း စီမံခန့်ခွဲမှု ကျွမ်းကျင်မှု ပရိုဖိုင် (Skill Profile: Autonomous Multi-Agent Systems Orchestration)

## ၁။ ကျွမ်းကျင်မှုဆိုင်ရာ အထောက်အထား (Skill Identity)
ဤကျွမ်းကျင်မှုသည် AI အေးဂျင့်များအား chat-based အဆင့်မှ လုပ်ငန်းခွင်၏ အမှန်တကယ် အားကိုးရသော အဖွဲ့ဝင်များအဖြစ် ပြောင်းလဲပေးရန် ရည်ရွယ်သည်။

- **Skill Name:** Persistent Multi-Agent Orchestrator (အမြဲတမ်းဖွင့်ထားသော AI အေးဂျင့် အဖွဲ့အစည်း စီမံခန့်ခွဲသူ)
- **Core Function:** Role-based delegation, 24/7 Autonomy, Centralized Memory Sync.

---

## ၂။ စတင်အသုံးပြုရမည့် အခြေအနေများ (Trigger Conditions)
- လုပ်ငန်းများကို လူသားအင်အား အနည်းငယ်ဖြင့် အရှိန်အဟုန်မြှင့် (Scaling) လုပ်ဆောင်လိုသောအခါ။
- ၂၄/၇ နောက်ကွယ်မှ အလုပ်လုပ်ပေးမည့် အေးဂျင့်များ လိုအပ်သောအခါ။
- Developer, Marketer, PM စသည့် အထူးပြု အခန်းကဏ္ဍများ လိုအပ်လာသောအခါ။

---

## ၃။ လုပ်ငန်းစဉ်ဆိုင်ရာ ယုတ္တိဗေဒ (The Logic Engine)

### Method A: Infrastructure Provisioning
အေးဂျင့်များသည် ၎င်းတို့၏ ကိုယ်ပိုင် Workspace (Dedicated VPS/Machine) တွင် လွတ်လပ်စွာ အလုပ်လုပ်ရမည်။

### Method B: Security & Isolation
အေးဂျင့်ကို ဝန်ထမ်းသစ်ကဲ့သို့ သဘောထားပြီး "Least Privilege" မူဝါဒအတိုင်း ကန့်သတ်ခွင့်ပြုချက်များသာ ပေးရမည်။

### Method C: Cost & Model Optimization (OpenRouter)
| အေးဂျင့် | အခန်းကဏ္ဍ | မော်ဒယ် | အားသာချက် |
| :--- | :--- | :--- | :--- |
| **Bernard** | Developer | Claude Opus | Reasoning (ဉာဏ်ရည်) |
| **Claw** | SysAdmin | Claude Opus | စနစ်စီမံခန့်ခွဲမှု |
| **Vale** | Marketer | Claude Sonnet | မြန်ဆန်မှု |
| **Gumbo** | Assistant | Claude Sonnet | အထွေထွေအကူအညီ |

### Method D: Centralized Memory Syncing (The Brain)
အေးဂျင့်များအကြား သတင်းအချက်အလက် မျှဝေရန် `Brain` folder အတွင်းရှိ Markdown ဖိုင်များကို အသုံးပြု၍ Sync လုပ်ရမည်။

## ၄။ လုပ်ဆောင်နိုင်စွမ်း ကန့်သတ်ချက်များ (Skill Constraints)
- **No Unfettered Access:** အသုံးပြုသူ၏ ကိုယ်ပိုင်ဖိုင်များနှင့် စက်ထဲသို့ အကန့်အသတ်မဲ့ ဝင်ရောက်ခွင့် မရှိစေရ။
- **API Tokens Only:** Personal Subscriptions များ အသုံးမပြုရ။
- **Environment Lock:** ခွင့်ပြုထားသော Workspace ပြင်ပတွင် အလုပ်မလုပ်ရ။
