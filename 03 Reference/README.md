- **Root Directory:** System Critical Files (`AGENTS.md`, `MEMORY.md`, `SOUL.md` etc.) သာ ထားရှိရမည်။
- **📂 01 Personal:** Nolan ၏ ကိုယ်ရေးကိုယ်တာ ကိစ္စများ။
- **📂 02 Work:** Professional Projects & Business Strategy (Active projects like Bots, Plans).
- **📂 03 Reference:** Knowledge Base, Documentation, System Configs, Tech Specs.
- **📂 04 Quick Share:** လုံခြုံစွာ ယာယီမျှဝေရန် ဖိုင်များ။ (Do not use as long-term storage).
- **📂 00 Backups:** Manual/Auto backups.
- **📂 99 Archive:** မသုံးတော့သော ဖိုင်ဟောင်းများနှင့် Logs များ။

**စည်းကမ်း:** Folder အဆင့် ၅ ဆင့်ထက် မပိုရ။ အဆင့်တစ်ခုစီတွင် Folder ၉၉ ခုထက် မပိုရ။ (01-99 Numbering သုံးပါ)။
